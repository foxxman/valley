# Settlement Prototype (Frontend)

Браузерный прототип top-down игры на **Vite + TypeScript + Phaser 3**.
Сейчас: бесконечный чанковый мир, персонаж и камера по центру, инвентарь на 20 ячеек, сбор четырёх цветов и разборка деревьев и сплошного камня клавишей E. Сид мира хранится в игре на сервере, сорванный цветок, надбитое дерево и добытый камень — в журнале карты. Игроки, которые знают id, заходят в одну карту и видят друг друга. Рюкзак у каждого свой в каждой игре.

Для AI/LLM: подробный разбор архитектуры и алгоритмов — в [`AGENTS.md`](./AGENTS.md).

## Требования

- Node.js 20+
- npm 10+

## Установка

```bash
cd frontend
cp .env.example .env
npm install
```

## Скрипты

| Команда | Режим | Описание |
|---------|--------|----------|
| `npm run dev` | development | Dev-сервер Vite с HMR. По умолчанию: http://localhost:5173 |
| `npm run build` | production | Проверка TypeScript и сборка в `dist/` |
| `npm run preview` | production preview | Локальный просмотр production-сборки. По умолчанию: http://localhost:4173 |

### Примеры

```bash
# разработка
npm run dev

# production-сборка
npm run build

# проверка собранного билда
npm run preview
```

## Управление

- **W / A / S / D** или **стрелки** — перемещение. Взгляд запоминает последнюю ось; если зажаты обе, побеждает клавиша, нажатая позже. До первого шага взгляд вниз
- **E** — действие. Если по взгляду стоит дерево или сплошной камень, это один удар: над клеткой появляется полоска прочности. Десять ударов голой рукой роняют дерево и кладут 4 древесины. Камень держится вдвое дольше, двадцать ударов, и кладёт 5 камней, а клетка становится травой. Осколки камня не добываются. Иначе собирается цветок под ногами или на соседней клетке по взгляду. Рамка показывает цель. Пока запрос идёт, повторное E игнорируется. В поле ввода и при открытом инвентаре **E** не срабатывает
- **I** — инвентарь: сетка 5×4. **Escape**, «Закрыть» или клик по фону закрывают её. Пока она открыта, персонаж не ходит. В поле ввода **I** не перехватывается
- Спрайт персонажа — Kenney Roguelike Characters (лёгкий bounce по вертикали)
- Трава / вода / берег (прямой, внешний и внутренний угол) — Kenney + custom

## Ассеты

Лежат в `public/assets/` (раздаются статикой Vite), по одному файлу на рисунок. Повороты берега делает код, отдельные копии на стороны света не хранятся.

```text
public/assets/
  player.png
  soil/grass.png
  stones/
  vegetation/          # деревья, цветы, пучок травы, lily.png
  items/               # иконки предметов, которых нет на карте (wood.png, stone.png)
  water/
```

Лицензия паков Kenney: **CC0**. Источники выбранных кадров — в [`public/assets/README.md`](./public/assets/README.md).

## Переменные окружения

Скопируйте `.env.example` → `.env` и при необходимости измените значения.
Все клиентские переменные должны начинаться с `VITE_` (требование Vite).

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `VITE_DEV_PORT` | `5173` | Порт dev-сервера (`npm run dev`) |
| `VITE_PREVIEW_PORT` | `4173` | Порт preview (`npm run preview`) |
| `VITE_CHUNK_SIZE` | `16` | Сторона чанка в тайлах. У всех клиентов одной игры должна совпадать |
| `VITE_TILE_SIZE` | `32` | Размер тайла на экране (исходные PNG — 16×16, масштабируются) |
| `VITE_PLAYER_SPEED` | `160` | Скорость персонажа (пиксели в секунду) |

После изменения `.env` перезапустите `npm run dev`.

## Структура

```text
frontend/
  public/assets/            # curated-текстуры 16×16
  src/
    main.tsx                 # React-оболочка
    app/                     # маршруты
    auth/                    # форма входа и сессия
    lobby/
    game/
      assets.ts             # Ключи и URL текстур
      config.ts
      env.ts
      scenes/WorldScene.ts
      entities/Player.ts
      entities/RemoteAvatar.ts
      inventory/             # модалка, запрос при входе, иконки цветов, древесины и камня
      map/                   # журнал клеток, сбор и удар
      net/channel.ts
      ui/Minimap.ts
      world/
        tiles.ts
        chunkWorld.ts        # чанки, журнал поверх сида, snapshot
        gatherTarget.ts      # клетка действия: дерево или камень по взгляду, иначе цветок
        nodes.ts             # прочность разрушаемых объектов
        generate-chunk/      # пруд, хребет, декор
        terrainVisual.ts     # water / straight / corner / inner
  .env.example
  index.html
  vite.config.ts
```
